Política de Privacidade

A privacidade dos nossos usuários é importante para o BeautyDesk. Esta política explica como as informações são utilizadas dentro da plataforma.

1. Coleta de informações

Podemos coletar informações fornecidas pelo usuário, como nome, e-mail, telefone e dados do salão para funcionamento do sistema.

2. Uso das informações

As informações são utilizadas para oferecer os recursos do BeautyDesk, melhorar a experiência do usuário e manter o funcionamento da plataforma.

3. Proteção dos dados

Buscamos manter os dados protegidos e utilizados somente para finalidades relacionadas ao serviço.

4. Compartilhamento de informações

Os dados dos usuários não são vendidos ou compartilhados de forma indevida com terceiros.

5. Atualizações da política

Esta política poderá ser atualizada para acompanhar melhorias e mudanças no serviço.
